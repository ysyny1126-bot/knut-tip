# knut-tip

한국교통대학교 충주캠퍼스 신입생을 위한 「교통대 꿀팁 가이드」. 선배들이 모은 맛집·카페·숨은 장소·꿀팁을 한 페이지에 정리했습니다.

사이트: https://ysyny1126-bot.github.io/knut-tip/

## 주요 기능

- 검색, 빠른 필터, 한국 시간 기준 "지금 영업 중" 표시 (1분마다 갱신)
- 오늘 뭐 먹지 룰렛: 종류·예산·영업 중·학교 근처·혼밥·찜한 곳 조건으로 한 곳 뽑기
- 오늘의 학식: 학생식당(한식·일품), 교직원식당, 생활관식당 메뉴를 학생들이 올리고 고침, 공식 식단표 링크
- 장소 상세 창: 정보, 영업 상태, 찜, 리뷰(별점·사진 3장)
- 식당별 질문과 답변(Q&A)
- 악플 관리: 욕설 필터, 신고 3건 자동 숨김, 관리자 패널(리뷰·Q&A 숨김·복원·삭제)
- 라이트·다크 모드 전환 버튼 (처음엔 기기 설정을 따르고, 고른 모드는 기억), 휴대폰 화면 지원

리뷰·Q&A·학식 메뉴는 claude.ai 아티팩트의 공유 저장소를 씁니다. GitHub Pages에서 열면 이 세 기능은 "준비 중" 안내와 공식 식단표 링크만 보이고, 나머지 기능은 모두 동작합니다.

## 파일

- `index.html` — 사이트 전체 (외부 파일 없이 바로 열림)
- `data/items.json` — 정리된 장소 데이터

## 배포 (GitHub Pages)

1. `index.html`을 고친 뒤 `main` 브랜치에 커밋하고 푸시합니다.
2. 저장소 Settings → Pages에서 Source가 `main` / `/ (root)`로 되어 있으면 1~2분 뒤 위 주소에 반영됩니다.
